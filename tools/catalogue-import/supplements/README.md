# supplements/

Sections the source documents do not carry, supplied from the AAUP website by
the app's owner and kept separate from the parsed output so their provenance is
never in doubt.

Each file names the program it belongs to, the section it fills, and why it is
here. The parsers merge these in and mark every merged section with
`suppliedFrom`, so nothing in catalogue.json or ai-data-science.json can be
mistaken for something the PDF or the docx actually printed.

Each supplement must reconcile: adding it makes the program's sections sum to
the degree total the source already states. That is the check that makes a
supplement safe to accept — it is not new information about the total, it is
the part the source dropped.
